# Contributing to Web Tempo Sync

We welcome contributions to the Web Tempo Sync API specification and explainer.

## Code of Conduct

All contributors are expected to adhere to the [W3C Code of Ethics and Professional Conduct](https://www.w3.org/policies/code-of-conduct/).

## Contributor License Agreement

Specifications in this repository are developed under the W3C Community Contributor License Agreement (CLA). Before substantial contributions can be merged, you may be asked to sign the CLA or confirm your affiliation with a member organization.

## How to Contribute

1. Open an issue to discuss proposed additions, questions, or architectural changes.
2. Submit pull requests for editorial improvements, spec refinements, or explainer updates.
3. Keep prose simple, clear, and direct. Avoid marketing language. Avoid em-dashes.
4. Verify that bikeshed compiles cleanly before submitting large spec edits.
